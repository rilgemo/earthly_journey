# Earthly Journey — Milestones

## 2026-06 — Identity Milestone

**Sandbox**: Identity Exists
Three agents with differentiated skill profiles (farming/arcane/forging)
no longer converge to a single dominant action (meditate) regardless of
physiological state. Verified across 72 simulated ticks under randomized
need noise — each agent's top action held >35% selection rate (actual:
100% each), confirming skill-based identity survives physiological
pressure once need was decoupled from the influence channel.

**Journey**: Identity Becomes Observable
A player can ask what an NPC (lao_zhou) has been doing and receive a
qualitative narrative, never raw statistics. The narrator only reports
patterns that genuinely exist in the underlying action log.

**Journey**: Identity Can Drift
Sustained behaviour gradually nudges an NPC's daily schedule within a
bounded range (±2 ingame hours), computed as a deviation from a frozen
baseline rather than as accumulating mutation — change exists, but a
person does not become unrecognisable.

**Journey**: Player Remembers Change
Re-observing an NPC after sufficient elapsed time produces a comparative
narrative against the player's own memory of a prior observation —
including correctly reporting "no change" when drift has already
plateaued, rather than inventing further progression.

Why this matters: this is the first point at which Earthly Journey
behaves less like a simulator producing numbers and more like a world
a player can return to and recognise as having continued without them.
