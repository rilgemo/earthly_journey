# 04 Memory System

## Current Status

No explicit agent memory system is implemented yet.

Current persistent knowledge is represented through player state, discovered skills, discovered actions, inventory, equipment, messages, and saved game data.

## Memory vs Skill

Skills represent capabilities and identity.

Memory should eventually represent learned context, relationships, preferences, fear, trust, and bias. It should not replace the skill system.

## Future Direction

A future memory system may support:

- Learned behavioral bias
- Trust and fear relationships
- Reactions to repeated player actions
- Agent history
- Long-term world consequences

This document is intentionally a placeholder until memory is explicitly implemented.
