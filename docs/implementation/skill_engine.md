# Skill Engine Implementation Mapping

This document maps the current skill system to the future learning model.

## Current Skill Role

Skills currently define:

- Character capabilities
- Derived stats
- XP
- Level
- Equip identity
- Slot constraints

## Future Learning Role

In the future simulation kernel:

- Skill XP is structured personal learning.
- Memory is broader behavioral reinforcement.
- Equipped skills define active capabilities.
- Skill growth should remain separate from social reputation.

## Mapping

| Current Skill Concept | Future Kernel Concept |
| --- | --- |
| Skill XP | Personal learning reinforcement |
| Skill level | Capability progression |
| Equipped skill | Active identity component |
| Hidden skill | Discovery-gated knowledge |
| Skill stat bonus | Capability modifier |
| Skill synergy | Behavior/action affordance |

## Implementation Rule

Do not make skills a general memory system.

Skills represent structured capability growth. Memory represents behavioral bias and remembered context.
