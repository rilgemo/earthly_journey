# Civilization Memory Formation Layer v1

Civilization Memory is a downstream compression layer for recurring emergent structures across time.

It is not storage.

It is not a behavior system.

## Inputs

Read-only sources:

- Culture traces
- Settlement snapshots
- Behavioral Signature history
- Demand history curves
- Resource Geography evolution
- Migration pressure logs
- Causal Isolation reports

## Boundary

Civilization Memory must never influence:

- Intent generation
- Behavior
- Culture detection
- Settlement formation
- Demand systems
- Field systems

## Output

The output artifact is `civilizationMemoryTrace`.

It explains why civilizations persist, not just how they emerge.
