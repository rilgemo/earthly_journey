# Civilization Myth Formation Layer v1

Civilization Myth is a downstream interpretive system.

It explains how civilizations narrate their own persistence.

It does not reconstruct factual causality.

## Inputs

Read-only sources:

- Civilization Memory Layer
- Culture Emergence Layer
- Settlement history
- Demand persistence patterns
- Behavioral Signature aggregates
- Migration pressure history

## Boundary

Myth must never influence:

- Civilization Memory
- Culture detection
- Settlement formation
- Demand system
- Intent systems
- Behavior systems

## Output

The output artifact is `mythTrace`.

It represents how civilizations explain themselves, not just how they behave or persist.
