# Culture Emergence Model v1

Culture is a read-only emergent property derived from stabilized cross-agent behavior.

It is not:

- Profession system
- RPG class system
- Skill system
- Economy system
- Identity system

## Authority Boundary

Culture must never influence:

- Intent generation
- Action selection
- Field dynamics
- Settlement formation
- Agent typology

Culture is downstream-only.

## Runtime Position

```text
Trace / Behavior / Settlement / Demand / Resource snapshots
-> Culture detection
-> Inspector / report output
```

No feedback path into simulation engine is allowed.

## Metrics

- Stability Index
- Drift Index
- Convergence Index
- Participation Entropy
- Cross-Settlement Spread

## Trace

Culture output must be represented as `cultureTrace`.
