# Resource Exchange Emergence Model v1

Resource Exchange Emergence owns exchange observation.

It detects context-dependent exchange patterns after completed action
execution. It produces exchange structure snapshots from resource asymmetry,
trust, proximity, behavioral history, and perceived need alignment.

## Authority

`/AGENTS.md` remains the single runtime authority.

Resource Exchange Emergence consumes:

- completed action traces
- action yield snapshots
- persistent activity cluster proximity analytics
- social trust and communication traces
- behavioral signatures
- perception alignment metrics

Other systems retain authority for:

- intent generation
- resolution model
- skill growth
- identity derivation
- elemental fields
- world demand execution

## Exchange Event

An exchange event is a trace-derived observation:

```js
{
  giver,
  receiver,
  resourcesOut,
  resourcesIn,
  contextState,
  trustLevel,
  reciprocityExpectation,
  temporalDistance
}
```

Resources remain local and typed. Food, material, protection, knowledge, and
arcane context retain their local meaning instead of being converted into a
unified value.

## Flow

```text
Action Execution
-> Action Yield
-> Exchange Detection
-> Reciprocity Update
-> TraceCollector
-> ReplayBuffer
```

## Ownership and Consumption

Resource Exchange Emergence owns:

- exchange event detection
- trust-weighted exchange graph snapshots
- reciprocity chain observation
- typed resource flow display data

Exchange snapshots are consumed by Replay, Inspector, and future higher-order
collective systems. Intent, resolution, inventory, resource physics, and world
mutation authority remain owned by their existing layers.
